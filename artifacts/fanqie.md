# 反切码注本（Fanqie Code Notebook）

> 密件册 · 1560 年代 · 明 · 性质：据史料复原 / Reconstructed · 关联游戏：`freq`

## 说明

**中文**：戚继光《纪效新书》所载反切码：取两首诗词，「重唱诗」取二十声母、「合声诗」取四十字韵母，声韵两两交叉得八百音码，再配以金鼓旗号传递——将本土音韵学化作军中密码。以下为依原法重构的编码页。

**English**: The fanqie code in Qi Jiguang's Jixiao Xinshu: take two poems — twenty initials from one, forty finals from the other — cross twenty initials with forty finals to form eight hundred sound-codes, then signal them by gongs, drums and flags, turning phonology into an army cipher. Below, one page reconstructed from the original method.

## 全文 / 摘录

**中文**：反切码要诀（依《纪效新书》重构）：先取「重唱诗」二十声母——金、葛、罕、坒……再取「合声诗」四十字韵母；声横韵纵，交格取字：某格之字即一军令。传令者以号笛、旗色、鼓点报出声韵序号，营中按册还原成字。「柳」= 声三 + 韵十二，「敌至东南」顷刻可传。

**English**: Fanqie essentials (reconstructed from the Jixiao Xinshu): take twenty initials from the "heavy-sung poem" and forty finals from the "joined-sound poem"; where row meets column stands one character — one order. A signaller sounds the initial-final numbers by whistle, flag or drumbeat, and the camp restores each character from the notebook: "enemy approaching from the southeast" travels in moments.

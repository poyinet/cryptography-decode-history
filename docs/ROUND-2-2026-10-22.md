### 本轮发现的架构债（未解决，记在账上）

- **源 ← 站 循环依赖**：知识源生成器要读主站 `poyi-site/` 的数据，而 CI 得靠一并 checkout `poyinet/www` + `POYI_ROOT` 绕过。彻底解法是把词表/章节/实体收归源自身，本轮未做。
- **分站产物不入库**：`build/site` 被 gitignore，发布靠 CI 或本地 publisher。好处是仓库不臃肿，坏处是「线上产物」与「git 提交」不是同一份真相 —— 需要靠 CI 每次重跑构建来保证一致。
- **本地 git 与远端已分叉**：API 推送产生的提交不在本地 git 历史里。本地已用 `git rm -r --cached .` + `git add -A` 重整过索引，但历史分叉仍在。下次同步前须 `git fetch origin && git reset --hard origin/main`（会丢弃本地未推送提交 —— 本地这两个提交已用 API 推上去了，安全）。

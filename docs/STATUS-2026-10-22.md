## 四、关键决策与踩坑记录

| # | 决策 / 问题 | 结论 |
|---|---|---|
| 1 | 放弃 `file://` 直开 | 换取 ESM / fetch / 构建 / Worker / IndexedDB / 增量构建；双击打不开的代价可接受 |
| 2 | 硬指标全删 | 用「知识总目录 + 覆盖矩阵 + 三档质量 + 抽检」替代数字验收 |
| 3 | 子目录名 `crypto.poyi.net` | 语义精确、与主站「玩」分工清晰 |
| 4 | `load-poyi.js` 硬编码路径 | 改为 `POYI_ROOT` env → 仓内 `poyi-site/` → 向上查找（CI 与本地同源） |
| 5 | 加密工具 `encode-assets.js` 密钥派生错误 | 按 `secure.js` 逐行重写，验证**与历史产物字节一致** |
| 6 | `secure.js` 解密从未成功 | `String.fromCharCode.apply(null, <字符串>)` 在 V8 抛 TypeError → 改为先转真数组；编年史正文恢复 |
| 7 | `secure.js` 执行早于密钥注入 | 改为密钥未就绪时等 DOMContentLoaded 重试 |
| 8 | GitHub Secret 加密 | libsodium `crypto_box_seal`，**全零 nonce**（不是随机 nonce，也不是 secretbox） |
| 9 | YAML 根级序列与映射混用 | 拆成 `entries:` 段；值内含 `:` 需引号；内嵌引号转全角 |
| 10 | 别名跨实体重复 | 拆成 `aliases`（唯一）+ `see`（可重复的跨实体引用） |
| 11 | tier1 名不副实 | 无一手/权威出处的 tier1 **自动降为 tier2**，不靠标注糊弄 |
| 12 | **架构债** | 知识源生成时读主站数据（源 ← 站 循环）。CI 靠一并检出主站绕过；彻底解法是把词表/章节/实体收归源自身、主站改为消费源产物 |
| 13 | `model.group()` 对字符串做 `for…of` | 把 `type:'era'` 拆成字符 → 13 类列表页一个都没生成。只对数组分组 |
| 14 | `Object.entries(map)` 用在 `Map` 上 | `byType` 恒空。改用 `Map` 原生迭代 |
| 15 | `.gitignore` 的 `site/` | 误伤 `tools/site/` 整个目录未入库。删该行（`build/` 已覆盖 `build/site`） |
| 16 | `api-push.js` 依赖本地 git 历史 | 远端有 API 建的提交 → 本地 `fatal: bad object`。改为基于远端树逐文件比对 blob sha |
| 17 | `publish-crypto-repo.js` 用 Contents API | 946 文件要 946 次 PUT、CNAME 报 422。改用 **Git Trees API 一次提交**（内联 content），CNAME 保留远端版 |
| 18 | 审核器重跑抹掉人工结论 | 生成器改为**保留**既有「人工结论」段 |
